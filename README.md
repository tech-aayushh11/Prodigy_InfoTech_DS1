### ✅ Task 02 - Exploratory Data Analysis (EDA)
**Objective:**
Perform data cleaning and exploratory data analysis on the Titanic dataset to explore relationships between variables and identify patterns and trends.

**Dataset:** Titanic Dataset (train.csv)

**Steps Performed:**
- Loaded and explored the dataset
- Checked shape, data types and basic info
- Identified and handled missing values
- Dropped irrelevant columns
- Filled missing Age with median
- Filled missing Embarked with mode

**Charts Created:**
- 📊 Survival Count
- 👫 Survival by Gender
- 📈 Age Distribution
- 🚢 Survival by Passenger Class
- 🔥 Correlation Heatmap

**Key Findings:**
- More females survived than males
- Passengers in 1st class had higher survival rate
- Most passengers were aged between 20-35
- Fare and Pclass are strongly correlated

**Tools Used:** Python, Pandas, Matplotlib, Seaborn, Jupyter Lab
